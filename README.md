# Site institucional - Colégio Ayrton Senna da Silva

Landing page responsiva criada a partir da estrutura do projeto original enviado, reformulada para uma apresentação institucional do Colégio Estadual Ayrton Senna da Silva, em Foz do Iguaçu - PR.

## Tecnologias
- HTML5 semântico
- CSS3 responsivo
- JavaScript vanilla
- Google Fonts
- Logo fornecida pelo usuário

## Funcionalidades
- Menu responsivo para celular
- Rolagem suave
- Animações de entrada por seção
- Botão voltar ao topo
- Links de telefone, e-mail e localização
- Layout desktop/tablet/mobile
